This repository holds **version 1.2** of the Sparta Tic Tac Toe app (Node.js 20). The app source lives, uncompressed, in the [`app/`](./app) folder at the root of the repo.

## Purpose

This repo is the source used to build a **Jenkins CI/CD pipeline**. Keeping a dedicated, synced copy of the app here means the pipeline has a clean, versioned starting point to build, test, and deploy from.

## Contents

- `app/` the Tic Tac Toe application code (v1.2)
- `.gitignore` standard Node ignores (keeps `node_modules`, logs, etc. out of the repo)

## Running the app locally

```bash
cd app
npm install
npm start
```
